## Capture constraints

The replacement will use browser-native state changes and clean hard cuts. There will be **no reused Payroll shot**, no long logo hold, no fake transaction/receipt, no static screenshot panning, and no long caption blocks. Demo Mode is allowed only where its simulated marker remains clearly visible. The Markets segment may show its Mainnet execution gate, but must never be framed as completed trade settlement.

## Acceptance test

The cut is rejected unless an independent viewer can identify four live outcomes without narration: a prepared private route, a changed disclosure packet, a governed allocation/release state, and an aggregate proof state. The final result must be under 120 seconds, browser-chrome-free, 1920×1080 at 60 fps, H.264, and use a clean 2–3 second close.
