# STRK20 Demo Video Duration Verification

**Verified:** 25 August 2026

The official STRK20 hackathon hub requires **“a 3-minute demo video”** for a project to be scored. The rule is phrased as a required deliverable, not as “up to three minutes,” and it does **not** state a separate numeric minimum or maximum. The prudent interpretation is therefore to deliver a video that is approximately **three minutes**, rather than relying on the 81-second judge cut alone.

| Item | Official wording / measured result | Assessment |
|---|---|---|
| Official demo-video requirement | “Your 3-minute demo video”; “To be scored, it needs: … A 3-minute demo video.” | Treat 3 minutes as the required target. |
| Stated minimum duration | None stated. | There is no official claim that 81 seconds meets a minimum. |
| Current Veyra outcome-led cut | 81.000 seconds. | Strong short judge cut, but not a safe replacement for the required three-minute deliverable. |

The 81-second version remains the strongest **teaser/judge preview**. If used as the official submission video without an explicit rule clarification, it carries compliance risk. A three-minute master should preserve its outcome-led core and add authentic, non-repetitive live proof around it rather than reverting to the rejected screenshot montage.
