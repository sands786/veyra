# STRK20 Private Sprint — Comparative Scorecard

**As of:** 25 August 2026

## Method

The official panel—not this analysis—will score submissions after the deadline. The official rubric is STRK20 integration depth (**30%**), working Mainnet product (**30%**), innovation (**25%**), and documentation/open-source quality (**15%**). The official hub currently has no public judge ranking. This scorecard is an analytical estimate based on the hub’s public requirement fields, each repository’s `strk20.json`, deployed-contract/transaction claims, live demos, videos, source-tree scope, and explicit limitations.

The “official-data top ten” is a **completeness proxy**, not a claim of official placing. The hub data supports a transparent comparison because it exposes verified transaction count, listed contracts, demo/video/mainnet flags, activity, and some structured project assessments.

### Scoring interpretation

The numeric estimates are deliberately conservative. They do not infer a completed Mainnet transaction from a polished UI, do not treat a contract address as an end-to-end workflow, and do not award production execution for Demo Mode. Veyra’s technical integration score reflects its verified pool receipts and strict wallet/receipt boundary; its Mainnet product score is reduced because its public evidence does not show a fully resolved recipient-side private delivery from Veyra’s own workflow.

The rows are not perfectly ordered by the proxy because the final estimate uses deeper repository evidence. In particular, the evidence proxy favors Morrow’s hub flags, while its own README reports a less complete contract/user-flow situation. Conversely, Crosslink is a serious non-proxy challenger because its repository documents three Mainnet transactions, an API/package, and a live privacy-refusal mechanism.

## Veyra’s comparative placement

If Veyra were publicly registered today, the defensible estimate is a **middle-to-lower half of this ten-project competitive set**, approximately **#8–#10**, not top three. Its documentation may be among the strongest. Its product breadth is also unusual. However, hackathon scoring weights functioning Mainnet delivery twice as heavily as documentation, and the projects above Veyra can generally point to a stronger app-owned, end-to-end, onchain action or deployed anonymizer lifecycle.

Veyra’s effective official placement today is **not rankable** because `sands786/veyra` is absent from the official registry and generated project dataset. This is not a quality judgement; it is a submission-visibility blocker.
