# STRK20 Private Sprint source notes

Official rules page: https://strk20.starknet.io/hackathon
Official hackathon repository: https://github.com/starkience/strk20-hackathon

Key requirements gathered on 2026-08-19: the sprint runs August 14–31, 2026; submissions close August 31 at 23:59 UTC; winners are announced September 4; prize pool is $5,000 paid in STRK ($2,500 / $1,500 / $1,000). Projects must use a public, open-source repository with a license. The repository should contain a root strk20.json with at least three successful mainnet transaction hashes touching the live STRK20 pool, a three-minute demo_video URL, and optionally contracts and demo_url. A public live demo is required for scoring. Judging weights are 30% STRK20 integration depth, 30% working mainnet product, 25% innovation, and 15% documentation/open-source quality.

For Veyra teaser messaging, do not claim that local persisted records or generated links are real settlement. Use accurate language: private payroll, treasury policy and approvals, sealed-bid private markets, selective disclosure, launchpad governance, and wallet-signed/receipt-confirmed Starknet settlement boundaries. The teaser can be a product vision/demo narrative, but must not fabricate mainnet transaction hashes or imply that user funds moved unless user-provided evidence exists.

The prior VeilPay teaser file was not found in /home/ubuntu by media extension search, so the new teaser should preserve the established Veyra visual identity from the live product: Obsidian black, Moon Ivory, Deep Tide, Emerald privacy signal, Vermilion action accent, editorial institutional-finance tone, and transparent shield mark.
